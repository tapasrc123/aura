## SYNOPSIS

Checks for permanent active role assignments

## SYNTAX

```powershell
Test-AuCisaPermanentRoleAssignment [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Permanent active role assignments SHALL NOT be allowed for highly privileged roles.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaPermanentRoleAssignment
```

Returns true if no roles have permanent active assignments
