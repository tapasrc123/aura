## SYNOPSIS

Checks if guest invitations are restricted to admins

## SYNTAX

```powershell
Test-AuCisaGuestInvitation [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Only users with the Guest Inviter role SHOULD be able to invite guest users.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaGuestInvitation
```

Returns true if guest invitations are restricted to admins
