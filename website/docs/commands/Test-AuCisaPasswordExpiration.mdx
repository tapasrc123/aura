## SYNOPSIS

Checks if passwords are set to not expire

## SYNTAX

```powershell
Test-AuCisaPasswordExpiration [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

User passwords SHALL NOT expire.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaPasswordExpiration
```

Returns true if all verified managed domains have password expiration configured
to be of 100 years or greater
