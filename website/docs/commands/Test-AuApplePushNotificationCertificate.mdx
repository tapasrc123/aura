## SYNOPSIS

Check the validity of the Apple Push Notification Service (APNS) Certificate for Intune.

## SYNTAX

```powershell
Test-AuApplePushNotificationCertificate [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

The Apple Push Notification Service (APNS) Certificate is required for managing Apple devices with Microsoft Intune.
This command checks if the APNS certificate is valid and not expired.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuApplePushNotificationCertificate
```

Returns true if the APNS certificate is valid for more than 30 days, false if it is expired or expiring soon.
