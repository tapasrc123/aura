## SYNOPSIS

Tests if app registration owners have Multi-Factor Authentication (MFA) enabled.

## SYNTAX

```powershell
Test-AuAppRegistrationOwnersWithoutMFA [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

This function checks all Entra ID app registrations and verifies that their owners have MFA registered.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuAppRegistrationOwnersWithoutMFA
```
