## SYNOPSIS

Checks for notification on role assignments

## SYNTAX

```powershell
Test-AuCisaAssignmentNotification [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Eligible and Active highly privileged role assignments SHALL trigger an alert.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaAssignmentNotification
```

Returns true if notifications are set for all roles
