## SYNOPSIS

Checks state of DKIM for all EXO domains

## SYNTAX

```powershell
Test-AuCisaDkim [[-Selector] <String>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

DKIM SHOULD be enabled for all domains.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaDkim
```

Returns true if DKIM record exists and EXO shows DKIM enabled
