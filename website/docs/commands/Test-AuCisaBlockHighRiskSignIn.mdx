## SYNOPSIS

Checks if Sign-In Risk Based Policies - MS.AAD.2.3 is set to 'blocked'

## SYNTAX

```powershell
Test-AuCisaBlockHighRiskSignIn [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Sign-ins detected as high risk SHALL be blocked.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaBlockHighRiskSignIn
```

Returns true if at least one policy is set to block high risk sign-ins.
