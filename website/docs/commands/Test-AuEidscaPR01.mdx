## SYNOPSIS

Checks if Default Settings - Password Rule Settings - Password Protection - Mode is set to 'Enforce'

## SYNTAX

```powershell
Test-AuEidscaPR01 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

If set to Enforce, users will be prevented from setting banned passwords and the attempt will be logged.
If set to Audit, the attempt will only be logged.

Queries settings
and returns the result of
graph/settings.values -eq 'Enforce'

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuEidscaPR01
```

Returns the result of graph.microsoft.com/beta/settings.values -eq 'Enforce'
