## SYNOPSIS

Imports Aura test result JSON files from disk into PowerShell objects.

## SYNTAX

```powershell
Import-AuraResult [-Path] <String[]> [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Loads one or more Aura test result JSON files and returns them as an array
of single-tenant AuraResults objects.
This is the standard way to load
previously saved results for use with Merge-AuraResult, Compare-AuTestResult,
or any future command that operates on result objects.

If a loaded JSON file contains a multi-tenant merged format (i.e.
a "Tenants"
array from a prior Merge-AuraResult call), each tenant is automatically
expanded into a separate result object.

Accepts file paths, glob patterns, or directory paths.
When a directory is
provided, it auto-discovers TestResults-*.json files inside it.

## EXAMPLES

### EXAMPLE 1

```powershell
# Load a single result file
Import-AuraResult -Path ./production.json
```

### EXAMPLE 2

```powershell
# Load all JSON files matching a glob
Import-AuraResult -Path ./results/*.json
```

### EXAMPLE 3

```powershell
# Load from a directory (auto-discovers TestResults-*.json)
Import-AuraResult -Path ./test-results/
```

### EXAMPLE 4

```powershell
# Pipe into Merge for a multi-tenant report
Import-AuraResult -Path *.json | Merge-AuraResult | Get-AuHtmlReport | Out-File report.html
```

## PARAMETERS

### -Path

One or more paths to JSON result files, glob patterns, or directories.
- File path:  ./production.json
- Glob:       ./results/*.json
- Directory:  ./results/  (discovers TestResults-*.json inside)
