## SYNOPSIS

Returns all the members of the specific group ID.

## SYNTAX

```powershell
Get-AuGroupMember [-GroupId] <Guid> [-Recursive] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Returns all the members of the specific group ID.
