## SYNOPSIS

Checks state of purview

## SYNTAX

```powershell
Test-AuCisaAuditLogPremium [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Microsoft Purview Audit (Premium) logging SHALL be enabled.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaAuditLogPremium
```

Returns true if audit log enabled
