## SYNOPSIS

Checks if the admin consent workflow is enabled

## SYNTAX

```powershell
Test-AuCisAdminConsentWorkflowEnabled [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

The admin consent workflow should be enabled.
CIS Microsoft 365 Foundations Benchmark v6.0.1

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisAdminConsentWorkflowEnabled
```

Returns true if admin consent workflow is enabled
