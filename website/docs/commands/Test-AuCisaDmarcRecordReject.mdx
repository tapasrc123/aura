## SYNOPSIS

Checks state of DMARC records for all exo domains

## SYNTAX

```powershell
Test-AuCisaDmarcRecordReject [-Strict] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

The DMARC message rejection option SHALL be p=reject.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaDmarcRecordReject
```

Returns true if DMARC record with reject policy exists for every domain
