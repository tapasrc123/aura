## SYNOPSIS

Check if any service principals are still using secrets instead of certificates or managed identities.

## SYNTAX

```powershell
Test-AuAppRegistrationsWithSecrets [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

It is advised to use certificates or managed identities instead of secrets for service principals.
This test checks if any service principals are still using secrets.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuAppRegistrationsWithSecrets
```

Returns true if no service principals are using secrets, otherwise returns false.
