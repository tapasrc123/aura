## SYNOPSIS

Disconnects the services connected through Connect-Aura.

## SYNTAX

```powershell
Disconnect-Aura [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Use this cmdlet to sign out of the services connected through Connect-Aura.
It also clears Aura Active Directory and GitHub session state.
Use
Disconnect-AuGraph when you only want to disconnect Microsoft Graph.

## EXAMPLES

### EXAMPLE 1

```powershell
Disconnect-AuGraph
```

### EXAMPLE 2

```powershell
Disconnect-Aura
```

### EXAMPLE 3

```powershell
Disconnect-Aura
```
