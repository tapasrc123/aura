## SYNOPSIS

Send an email with the summary of the Aura test results

## SYNTAX

```powershell
Send-AuMail [-AuraResults] <PSObject> [-Recipient] <String[]> [-Subject <String>] [-TestResultsUri <String>]
 [-CreateBodyOnly] [-UserId <String>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Uses Graph API to send an email with the summary of the Aura test results.

This command requires the Mail.Send permission in the Microsoft Graph API.

When running interactively this can be done by running the following command:

```
Connect-AuGraph -SendMail
```

When running in a non-interactive environment (Azure DevOps, GitHub) the app needs permission to send from a mailbox,
see https://aura.onetapas.com/docs/monitoring/email/ for instructions.

## EXAMPLES

### EXAMPLE 1

```powershell
Send-AuMail -AuraResults $AuraResults -Recipient john@contoso.com, sam@contoso.com -Subject 'Aura Results' -TestResultsUri "https://github.com/contoso/aura/runs/123456789"
```

Sends an email with the summary of the Aura test results to two users along with the link to the detailed test results.
