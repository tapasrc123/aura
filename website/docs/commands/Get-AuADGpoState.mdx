## SYNOPSIS

Collects Active Directory Group Policy state information.

## SYNTAX

```powershell
Get-AuADGpoState [-Refresh] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Collects GPO data including GPO objects, reports, permissions, and SYSVOL data.
Results are cached for the session to avoid repeated queries.
Connect-Aura -Service ActiveDirectory must complete successfully before this command can collect or return data.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-AuADGpoState
```

Returns cached GPO state or collects if not already cached.
Returns no data unless Active Directory was explicitly connected through Connect-Aura.

### EXAMPLE 2

```powershell
Get-AuADGpoState -Refresh
```

Forces a fresh collection of GPO state data from Active Directory.
