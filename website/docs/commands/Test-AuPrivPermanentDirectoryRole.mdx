## SYNOPSIS

Checks if Permanent Assignments for Entra ID roles exists

## SYNTAX

```powershell
Test-AuPrivPermanentDirectoryRole [[-FilteredAccessLevel] <String[]>] [-FilterPrincipal] <Object[]>
 [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

GET /beta/roleManagement/directory/roleAssignments?$expand=principal

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuPrivPermanentDirectoryRole -FilteredAccessLevel "ControlPlane" -FilterPrincipal "ExternalUser"
```
