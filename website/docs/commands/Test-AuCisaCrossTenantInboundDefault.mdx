## SYNOPSIS

Checks cross-tenant default inbound access configuration

## SYNTAX

```powershell
Test-AuCisaCrossTenantInboundDefault [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Guest invites SHOULD only be allowed to specific external domains that have been authorized by the agency for legitimate business purposes.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaCrossTenantInboundDefault
```

Returns true if cross-tenant default inbound access is set to block.
