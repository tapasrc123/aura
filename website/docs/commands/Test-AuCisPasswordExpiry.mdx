## SYNOPSIS

Checks if passwords are set to expire

## SYNTAX

```powershell
Test-AuCisPasswordExpiry [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Passwords should not be set to expire
CIS Microsoft 365 Foundations Benchmark v6.0.1

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisPasswordExpiry
```

Returns true if no passwords are set to expire
