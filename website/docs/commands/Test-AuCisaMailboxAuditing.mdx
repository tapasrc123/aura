## SYNOPSIS

Checks state of mailbox auditing

## SYNTAX

```powershell
Test-AuCisaMailboxAuditing [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Mailbox auditing SHALL be enabled.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaMailboxAuditing
```

Returns true if mailbox auditing is enabled.
