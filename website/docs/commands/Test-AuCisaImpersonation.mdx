## SYNOPSIS

Checks state of preset security policies

## SYNTAX

```powershell
Test-AuCisaImpersonation [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Impersonation protection checks SHOULD be used.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaImpersonation
```

Returns true if standard and strict protection is on
