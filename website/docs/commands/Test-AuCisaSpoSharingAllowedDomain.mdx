## SYNOPSIS

Checks state of SharePoint Online sharing

## SYNTAX

```powershell
Test-AuCisaSpoSharingAllowedDomain [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

External sharing SHALL be restricted to approved external domains and/or users in approved security groups per interagency collaboration needs.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaSpoSharingAllowedDomain
```

Returns true if sharing uses restricted domains
