## SYNOPSIS

Send an adaptive card in a teams channel with the summary of the Aura test results

## SYNTAX

### MSGraph

```powershell
Send-AuTeamsMessage [-AuraResults] <PSObject> [-TeamId] <String> [-TeamChannelId] <String>
 [-Subject <String>] [-TestResultsUri <String>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### Webhook

```powershell
Send-AuTeamsMessage [-AuraResults] <PSObject> [-TeamChannelWebhookUri] <String> [-Subject <String>]
 [-TestResultsUri <String>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Uses Graph API to send an adaptive card in a teams channel with the summary of the Aura test results.

This command requires the ChannelMessage.Send delegate permission in the Microsoft Graph API.

Note: Teamwork.Migrate.All application permission is required if running in a non-interactive environment (Azure DevOps, GitHub) to send messages to a channel.

When running interactively this can be done by running the following command:

```
Connect-AuGraph -SendTeamsMessage
```

When running in a non-interactive environment (Azure DevOps, GitHub) the ChannelMessage.Send permission
must be granted to the application in the Microsoft Entra portal.

## EXAMPLES

### EXAMPLE 1

```powershell
Send-AuTeamsMessage -AuraResults $AuraResults -TeamId '00000000-0000-0000-0000-000000000000' -TeamChannelId '19%3A00000000000000000000000000000000%40thread.tacv2' -Subject 'Aura Results' -TestResultsUri "https://github.com/contoso/aura/runs/123456789"
```

Sends an Adaptive Card in a Teams Channel with the summary of the Aura test results to the specified channel along with the link to the detailed test results.

### EXAMPLE 2

```powershell
Send-AuTeamsMessage -AuraResults $AuraResults -TeamChannelWebhookUri 'https://some-url.logic.azure.com/workflows/invoke?api-version=2016-06-01' -Subject 'Aura Results' -TestResultsUri "https://github.com/contoso/aura/runs/123456789"
```

Sends an Adaptive Card in a Teams Channel with the summary of the Aura test results to the specified channel along with the link to the detailed test results.
