## SYNOPSIS

Checks state of sharing policies

## SYNTAX

```powershell
Test-AuCisaCalendarSharing [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Calendar details SHALL NOT be shared with all domains.

## EXAMPLES

### EXAMPLE 1

```powershell
Test-AuCisaCalendarSharing
```

Returns true if no sharing policies allow uncontrolled calendar sharing.
